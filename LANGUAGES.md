# Languages

## Phone field (`PentaPhoneField.languageCode`)

ar, bn, de, el, en, es, fa, fr, hi, id, it, ja, ko, nl, pl, pt, ru, sv, th,
tr, uk, ur, vi, zh

## Firebase exception messages (`FirebaseExceptionConverter`)

ar_SA, de_DE, en_GB, en_US, es_ES, fr_FR, ko_KR, nl_NL, pl_PL, pt_PT, ru_RU,
sv_SE, th_TH, tr_TR, uk_UA, ur_PK, vi_VN, zh_CN

A locale without a country (e.g. `Locale('tr')`) matches the first entry with
the same language; unknown locales fall back to `en_US`.
